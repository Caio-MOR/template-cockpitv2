# Portable delegation

The main session owns intent, scope, and final acceptance. Delegate bounded execution when the active harness supports subagents, then obtain fresh independent verification for material changes.

When the harness exposes per-agent model selection and offers `gpt-5.6-luna`, use it with low reasoning effort for narrow, mechanical work. If either capability is unavailable, use the harness default or execute inline. This guidance is a preference, not an enforcement claim about any local configuration.

Give each worker an exact repository path, bounded task, completion command, iteration ceiling, and protected files. Run independent work in parallel only when the work does not overlap. A different author or fresh reviewer must verify material changes with reproduced evidence before acceptance.
